Welcome to the Velox Code Library. This site is a reference for the classes, functions, variables, types, constants and scripting features available in Velox.

For the best experience, use the Code Library inside the Velox application by selecting **Help > Code Library**. The in-application Code Library is integrated with Velox and is the recommended place to explore the scripting reference while you work.

This site and the Code Library documents installed with Velox are built from the same source. To update your local copy of the documentation, run:

```text
C:\ProgramData\Velox\_Update Velox Data from GIT.bat
```
