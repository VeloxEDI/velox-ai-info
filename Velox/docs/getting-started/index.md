This path is for new Velox users and implementers with access to a configured test environment.

1. Read [What Velox does](what-is-velox.md) for the product and service boundaries.
2. Learn the [core concepts](core-concepts.md): modules, Connections, Definitions, Flows and contexts.
3. Use the [Designer orientation](designer-orientation.md) to find configuration and operational tools.
4. [Create your first Flow](first-flow.md) with fictional data in the test context.

Do not begin in production. Confirm the selected system connection and test/production context before editing or running anything.

After the tutorial, use the detailed [Flow design guide](../design-and-build/flows/index.md) and [operations guide](../operate-and-troubleshoot/index.md).
