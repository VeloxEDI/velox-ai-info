After completing your first test Flow, choose the path that matches your responsibility:

| Goal | Continue with | You should be able to |
| --- | --- | --- |
| Install or upgrade | [Install and upgrade](../install-and-upgrade/index.md) | Plan dependencies, configure services/databases and validate or recover a deployment |
| Administer environments and services | [Administer Velox](../administer-velox/index.md) | Select contexts, configure General Setup, control services and manage shared modules |
| Build an integration | Data Connections and Definitions, then the [Flow guide](../design-and-build/flows/index.md) | Select dependencies, configure data, add ordered steps and choose a trigger |
| Exchange data | [Transport guide](../design-and-build/transports/index.md) | Choose a direction/protocol, configure security/retry and verify Transport Logs |
| Build an API | [APIs and OpenAPI](../design-and-build/apis-and-openapi/index.md) | Configure a REST Flow and API metadata, deploy behind an approved security boundary |
| Add scripts | [Velox Scripting guide](../design-and-build/scripting-code-library/index.md) | Use variables/Scriptlets, test PascalScript and open the generated Code Library |
| Operate and recover | [Operations guide](../operate-and-troubleshoot/index.md) | Interpret Flow/Transport Logs, diagnose dependencies and recover without duplicating side effects |

The deeper Design, Operations and Technical reference branches are being regenerated beneath these entry points. Existing public routes remain valid during the migration.
