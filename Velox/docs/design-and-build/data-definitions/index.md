A Data Definition describes structured data; a Connection describes how Velox reaches it. Create and test the Connection first.

- Review [Definition concepts](definition-concepts.md) and [common properties](common-definition-properties.md).
- Use a [DB Definition](database-definitions.md) for database data views, criteria and transactional updates.
- Choose a [File Definition](file/index.md) for Flat, XML, JSON, EDI or Excel data.

Definitions are shared by Flow data items, Maps, Reports and REST request/response configuration. Check usage before changing fields, delimiters, schema or update behaviour.
