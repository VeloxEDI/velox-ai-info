Build Velox integrations from reusable modules rather than starting with an isolated Flow step.

1. Choose and validate [Connections](connections/index.md) for each database or file location.
2. Define the structure with [Data Definitions](data-definitions/index.md).
3. Configure Flow data, ordered steps, trigger and completion policy in the [Flow guide](flows/index.md).
4. Add Maps, Reports, SQL, Variables or Scriptlets through the [transformations and reusable logic guide](transformations-output/index.md).
5. Exchange data through the [Transport guide](transports/index.md), or expose a REST Flow through [APIs and OpenAPI](apis-and-openapi/index.md).
6. Test in the correct context, inspect the Flow Log and verify actual output. For outbound work, also verify the later Transport Log result.

Use [Connect and define data](data-overview.md) for the preserved former design entry route.
