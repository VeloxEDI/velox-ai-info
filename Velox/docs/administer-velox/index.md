Velox administrators maintain shared settings, configuration contexts, modules, runtime services and recovery controls.

- [Configure General Setup](general-setup/index.md) for installation-wide behaviour.
- [Work with test and production configuration](environments/index.md) before editing or promotion.
- [Control Velox services](service-control/index.md) during changes and incidents.
- [Manage modules and folders](modules-and-folders/index.md) with usage and dependency checks.
- [Maintain and recover configuration](maintenance-and-recovery.md) through coordinated database and file controls.

Use least privilege and an approved change record. Confirm the selected context and current processing state before every administrative action.
